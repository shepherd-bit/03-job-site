# 03-job-site

![Preview](./# 03-job-site

![Preview](./images/preview-2.PNG)

A modern, clean, and intuitive job board landing page designed to connect job seekers with open roles, featuring job listings, filters, and a streamlined layout.

🔗 **[View Live Demo](https://shepherd-bit.github.io/03-job-site/)**

---

## 🚀 Features
* **Modern Job Board Layout:** Designed for clarity with dedicated sections for popular roles, features, and company stats.
* **Fully Responsive:** Adapts seamlessly to mobile devices, tablets, and wide-screen desktops.
* **Interactive Frontend Elements:** Custom user experience powered by modern client-side scripting.

## 🛠️ Tech Stack
* **Markup:** HTML5 (clean, semantic layout)
* **Styling:** CSS3 (modern layouts using flexbox/grid, custom styles, and responsive media queries)
* **Interactivity:** Vanilla JavaScript

## 💻 How to Run Locally

This is a completely static, client-side frontend project, which means there is no complex backend server setup required:

1. **Clone the repository:**
   ```bash
